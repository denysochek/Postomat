# Postomat - вдосконалення [Nova Parcel](https://github.com/FakerFox/nova-parcel)

Трекер посилок для **Нової пошти**, **Укрпошти** та **Meest** з темною темою, сповіщеннями та кращим UI.

## Можливості

- **Три перевізники:** Нова пошта, Укрпошта, Meest — через єдиний інтерфейс
- **Автоматичне виявлення перевізника** за форматом ТТН
- **Темна тема** (світла / темна / системна)
- **Сповіщення** про зміни статусу посилок
- **Відстеження за ТТН** без облікового запису (публічний трекінг)
- **Демонстраційний режим** з вигаданими даними для перевірки UI
- **macOS + Windows** (Electron)
- **Локальне сховище** даних (localStorage)

## Структура проєкту

```
postomat/
├── index.html              # Головна сторінка
├── app.js                  # Логіка UI та прив'язка до стану
├── mock-server.cjs         # Мок-API для локальної розробки
├── package.json            # Залежності та скрипти
├── tsconfig.json           # Конфігурація TypeScript
├── electron/
│   ├── main.js             # Головний процес Electron
│   └── preload.js          # Предзавантажувач (bridge)
├── src/
│   ├── types.ts            # Типи даних (Parcel, CarrierId тощо)
│   ├── assets/
│   │   └── styles.css      # Стилі з підтримкою темної теми
│   ├── carriers/
│   │   ├── base.ts         # Базовий клас адаптера
│   │   ├── novaposhta.ts   # Адаптер Нова пошти
│   │   ├── ukrposhta.ts    # Адаптер Укрпошти
│   │   ├── meest.ts        # Адаптер Meest
│   │   └── registry.ts     # Реєстр перевізників
│   └── store/
│       ├── parcel-store.ts # Централізоване сховище стану
│       └── theme.ts        # Менеджер теми (світла/темна/системна)
└── test/
    ├── carriers.test.cjs   # Тести адаптерів перевізників
    └── runner.cjs          # Запуск тестів
```

## Встановлення та запуск

### Розробка (браузер)

```bash
cd postomat
npm install
# Запуск мок-API для тестування без мережі
node mock-server.cjs
# Відкрийте index.html у браузері або через live-server
```

### Electron (macOS / Windows)

```bash
cd postomat
npm install
npm start
```

### Тести

```bash
npm test
```

## Формати ТТН

| Перевізник | Формат | Приклад |
|------------|--------|---------|
| Нова пошта | 14 цифр | `20450000000001` |
| Укрпошта | 2 літери + 9 цифр + 2 літери, або 11–14 цифр | `RA123456789UA` |
| Meest | 10–14 цифр | `5001234567890` |

## Теми

Перемикач теми у заголовку додатка (кнопка з іконкою Sonne/Місяця) або в Налаштуваннях → Темна тема.
Зберігається у localStorage та дотримується `prefers-color-scheme` системи.
